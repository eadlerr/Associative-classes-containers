# Лабораторная работа №4: Ассоциативные контейнеры и итераторы STL

## Описание проекта
Консольное приложение на языке **C++**, представляющее собой реестр спортивных мероприятий («Городской спорткомитет»). 
Проект демонстрирует работу со всеми **8 ассоциативными и неупорядоченными контейнерами** библиотеки STL.

## Используемые контейнеры STL (8 шт.)
В проекте реализованы операции добавления, удаления, редактирования, поиска и вывода для каждого контейнера:

1. **`std::map`** — `participants` (уникальные участники по ID).
2. **`std::set`** — `sports` (уникальный перечень видов спорта).
3. **`std::multimap`** — `teamMembers` (составы команд, ключи могут повторяться).
4. **`std::multiset`** — `leaderboard` (общий рейтинг, сортировка по убыванию через кастомный компаратор `RatingCmp`).
5. **`std::unordered_map`** — `eventsMap` (мероприятия и их даты, хеш-таблица).
6. **`std::unordered_set`** — `teams` (уникальный список команд).
7. **`std::unordered_multimap`** — `achievements` (достижения участников, у одного ID может быть несколько медалей).
8. **`std::unordered_multiset`** — `logs` (журнал системных событий).

## Архитектура классов
Проект использует классы из предыдущей лабораторной работы и дополняет их:
*   **`Person`** (абстрактный базовый класс) — содержит общие поля (ID, ФИО, возраст, страна, рейтинг).
*   **`Athlete`** (наследник `Person`) — спортсмен (добавлено поле «Медали»).
*   **`Coach`** (наследник `Person`) — тренер.
*   **`Event`** — соревнование (агрегирует `std::vector` спортсменов и тренеров).
*   **`SportsCommittee`** — главный класс, содержащий все 8 контейнеров и логику управления.
*   **`RatingCmp`** — класс, созданный для сортировки рейтинга по убыванию.

## Структура проекта
*   `main.cpp` — точка входа, главное меню.
*   `Menu.cpp / .h` — реализация интерактивных меню для каждого контейнера.
*   `FileManager.cpp / .h` — сохранение и загрузка данных (`sport_data.txt`), а также генерация отчета (`sport_report.txt`).
*   `Person.cpp / .h` — иерархия классов участников.
*   `Event.cpp / .h` — класс соревнования.
*   `SportsCommittee.cpp / .h` — класс, содержащий контейнеры.
*   `Utils.cpp / .h` — вспомогательные функции ввода-вывода и форматирования таблиц.
